## 核心问题（未整改 Demo 的通病）

1. **布局不占满**：`.demo-canvas { height: 620px }` 写死 → 容器高 > 620px 时下面空一大部分；容器高 < 620px 时死挤/溢出
2. **标题描述占空间**：`<h3>xxx</h3>` + `<p>描述...</p>` 非企业级，浪费垂直空间
3. **无统一工具栏**：无 ShDemoToolbar，无图标，无 tooltip → 用户"好多按钮没有图标，也没提示"
4. **无 i18n**：硬编码中文，未走 i18n() 函数
5. **多组件 Demo 内部 :height 写死**：`:height="420"` 同样导致不占满
6. **设计器不协调**：面板/舞台/属性未占满整个页面

## 整改方案

### 统一整改模式（每个 Demo 都遵循）

#### 1. 新建 `<module>/<Module>Demo.constants.ts`

```typescript
// 导出 mock 数据（从原 Demo 抽出，structuredClone 友好）
export const SAMPLE_<MODULE>: <XxxData> = { ... };
// 导出主操作（左侧）
export const <MODULE>_ACTIONS: ShDemoAction[] = [
  { key: "save", icon: Check, labelKey: "advanced.<module>.save", group: "data" },
  { key: "clear", icon: Delete, labelKey: "advanced.<module>.clear", group: "data" },
  // ...
];
// 导出次要操作（右侧 margin-left:auto）
export const <MODULE>_SECONDARY: ShDemoAction[] = [
  { key: "help", icon: QuestionFilled, tooltipKey: "advanced.<module>.help", iconOnly: true },
];
```

#### 2. 改写 `<Module>Demo.vue`

```vue
<script setup lang="ts">
import { computed, ref } from "vue";
import { ElMessage } from "element-plus";
import { i18n } from "@/lang";
import { <XxxComponent> } from "@/components/<module>";
import type { <XxxData> } from "@/components/<module>";
import ShDemoToolbar from "./components/ShDemoToolbar.vue";
import type { ShDemoAction } from "./components/demoTypes";
import { SAMPLE_<MODULE>, <MODULE>_ACTIONS, <MODULE>_SECONDARY } from "./<module>/<Module>Demo.constants";

const data = ref<<XxxData>>(structuredClone(SAMPLE_<MODULE>));
const <toggle>Visible = ref(true); // toggle 类响应式

const actions = computed<ShDemoAction[]>(() => <MODULE>_ACTIONS.map(a => ({ ...a })));
const secondaryActions = computed<ShDemoAction[]>(() =>
  <MODULE>_SECONDARY.map(a => a.key === "toggle<X>" ? { ...a, active: <toggle>Visible.value } : { ...a })
);

const createEmpty = (): <XxxData> => ({ ...structuredClone(SAMPLE_<MODULE>), /* 清空字段 */ });
const downloadJson = (data: unknown, filename: string): void => { /* Blob + a 标签 */ };

const onAction = (key: string): void => {
  switch (key) {
    case "loadSample": data.value = structuredClone(SAMPLE_<MODULE>); break;
    case "clear": data.value = createEmpty(); break;
    case "exportJson": downloadJson(data.value, "<module>.json"); break;
    case "toggle<X>": <toggle>Visible.value = !<toggle>Visible.value; break;
    case "help": ElMessage.info(i18n("advanced.<module>.message.helpHint" as any)); break;
  }
};

defineExpose({ loadData: (d?: <XxxData>) => { data.value = structuredClone(d ?? SAMPLE_<MODULE>); } });
</script>

<template>
  <div class="demo-root">
    <ShDemoToolbar
      :title-key="'advanced.<module>.title'"
      :actions="actions"
      :secondary-actions="secondaryActions"
      module="<module>"
      @action="onAction"
    />
    <div class="demo-stage">
      <<XxxComponent> :initial-<xxx>="data" />
    </div>
  </div>
</template>

<style scoped>
.demo-root { display: flex; flex-direction: column; height: 100%; width: 100%; overflow: hidden; background: var(--el-bg-color-page); }
.demo-stage { flex: 1; min-height: 0; overflow: hidden; }
</style>
```

#### 3. 追加 i18n keys

- `src/lang/zh_CN.ts` 末尾 `};` 前追加 `// ===== advanced.<module> =====` 分组
- `src/lang/en_US.ts` 对应英文翻译
- key 结构：`advanced.<module>.title` / `advanced.<module>.<action>` / `advanced.<module>.message.<xxx>`

```javascript
(() => {
  const panes = document.querySelectorAll('.el-tab-pane');
  let pane = null;
  panes.forEach(p => { if (p.style.display !== 'none' && p.offsetHeight > 0) pane = p; });
  const root = pane?.querySelector('.demo-root');
  const toolbar = root?.querySelector('.sh-demo-toolbar');
  const btns = toolbar?.querySelectorAll('button') || [];
  const noIcon = Array.from(btns).filter(b => !b.querySelector('.el-icon')).length;
  return {
    paneH: pane?.offsetHeight || 0,
    rootH: root?.offsetHeight || 0,
    diff: (pane?.offsetHeight||0) - (root?.offsetHeight||0),
    toolbar: !!toolbar,
    btns: btns.length,
    noIconBtns: noIcon,
    占满: Math.abs((pane?.offsetHeight||0)-(root?.offsetHeight||0)) <= 2,
    工具栏OK: !!toolbar && noIcon === 0,
  };
})()
```

## 假设与决策

### 假设

1. 底层 14 个组件的 Props 模式与批次 1 一致（`initial<Xxx>` + `readonly` + `update:<xxx>`/`save` events），实施时若发现差异则相应调整
2. 底层组件根样式都是 `height:100%` 或可通过外层 `.demo-stage` 撑满
3. 底层组件不监听 props 变化时，用 `:key` 强制重新挂载（参考 WhiteboardDemo 的 wbKey 模式）

### 决策

1. **统一不套壳**：沿用批次 1 决策，`ShDemoToolbar + .demo-stage` 包裹，不创建 AdvancedDemoShell
2. **constants.ts 集中管理**：每个模块新建 `<module>/<Module>Demo.constants.ts`，导出 mock 数据 + ACTIONS 常量
3. **多组件 Demo 保留 el-tabs**：MapDemo/IotDemo 保留内部 el-tabs，用 `.demo-stage` + `.sub-stage` 包裹每个 tab，移除 :height 写死
4. **KnowledgeGraphDemo 改分栏**：GraphViewer + GraphQueryBuilder 左右分栏（更适合企业级查询场景）
5. **demo 工具栏聚焦数据生命周期**：loadSample/clear/export/toggle/help，不重复底层工具栏功能
6. **toggle 类按钮响应式**：constants.ts 静态导出 + Demo.vue ref + computed 动态生成 actions
7. **i18n key 扁平结构**：`advanced.<module>.<action>.<field>`
8. **底层组件不支持的操作（如 run/validate）**：demo 工具栏按钮点击弹 ElMessage.info 提示"功能演示"，不阻塞

## 风险与应对

| 风险 | 应对 |
| --- | --- |
| 底层组件 Props 与预期不符 | 实施时先读底层组件源码确认 Props/Events，再写 Demo |
| 底层组件不支持 height:100% | 用 `:deep()` 覆盖根样式，或外层加 `position:relative` + 内层 `position:absolute; inset:0` |
| 多组件 Demo 内部 el-tabs 高度链断裂 | 参考批次 1 AdvancedComponentsDemo.vue 的 `:deep(.el-tabs__content) { flex: 1; }` 模式 |
| i18n key 冲突 | 所有 key 用 `advanced.<module>.` 前缀，避免与现有 key 冲突 |
| browser_use agent 切 tab 失败 | 验证脚本明确指示先点"高级组件库" tab，再点子 tab；若仍失败，用 Shell + curl 检查页面 HTML |
| 底层组件不监听 props 变化导致 clear/loadSample 无效 | 用 `:key` ref 强制重新挂载（参考 WhiteboardDemo 的 wbKey） |

### 关键发现与特殊处理

1. **OfficeEditor 高度问题**：根元素用 `:style="{ height: containerHeight }"`，`containerHeight = props.height ?? 600`。即使外层 `.demo-stage` 撑满，内联样式仍是 600px。**需修改 OfficeEditor.vue**：当 `props.height` 为 undefined 时用 `100%` 而非 `600px`。

2. **Map/Iot 子组件 `:height` 用于内部画布像素尺寸**：MapField 的 `canvasHeight = ref(props.height ?? 280)` 用于 SVG 坐标投影，不能简单改为 100%。**需用 ResizeObserver 动态计算高度**传入。

3. **RichTextCollab 监听 readonly**：`watch(() => props.readonly, ...)` 存在（第 41-52 行），toggleReadonly 可不重挂载。但 `html`/`toolbarMode` 不监听，loadSample/clear/切换模式仍需 `:key`。

4. **DigitalTwinDesigner 监听 scene**：`watch(() => props.scene, ...)` 存在（第 62-68 行），loadSample/clear 可不重挂载。但为一致性仍用 `:key`。

5. **KnowledgeGraphDemo 改为左右分栏**：GraphViewer（flex:1）+ GraphQueryBuilder（340px fixed），更适合企业级查询场景。

## 整改方案

### 共享基础设施

#### 1. 新增 `src/sample/components/useElementHeight.ts`

用于 Map/Iot 多组件 Demo 动态计算子组件高度：

```typescript
import { onMounted, onUnmounted, ref, type Ref } from "vue";

/**
 * 使用 ResizeObserver 动态追踪元素高度
 * 用于 Map/Iot 等需要 :height 像素值的子组件
 */
export function useElementHeight(
    target: Ref<HTMLElement | null>,
    options: { defaultHeight?: number; offset?: number } = {},
): Ref<number> {
    const { defaultHeight = 400, offset = 0 } = options;
    const height = ref(defaultHeight);
    let observer: ResizeObserver | null = null;

    const update = (): void => {
        if (!target.value) return;
        height.value = Math.max(100, target.value.clientHeight - offset);
    };

    onMounted(() => {
        if (!target.value) return;
        update();
        observer = new ResizeObserver(update);
        observer.observe(target.value);
    });

    onUnmounted(() => {
        observer?.disconnect();
        observer = null;
    });

    return height;
}
```

#### 2. 修改 `src/components/office/OfficeEditor.vue`（1 行改动）

```typescript
// 修改前（第 39 行）：
const containerHeight = computed(() => `${props.height ?? 600}px`);
// 修改后：
const containerHeight = computed(() => (props.height != null ? `${props.height}px` : "100%"));
```

同时在 `.office-editor` CSS 中补 `height: 100%` 作为 fallback（当内联样式为 100% 时生效）。

## 统一代码模式（参考批次 2 GanttDemo.vue）

### 标准模板（单组件 Demo）

```vue
<script setup lang="ts">
import { computed, ref } from "vue";
import { ElMessage } from "element-plus";
import { i18n } from "@/lang";
import { XxxComponent } from "@/components/xxx";
import type { XxxData } from "@/components/xxx";
import ShDemoToolbar from "./components/ShDemoToolbar.vue";
import type { ShDemoAction } from "./components/demoTypes";
import { SAMPLE_XXX, XXX_ACTIONS, XXX_SECONDARY } from "./xxx/XxxDemo.constants";

const data = ref<XxxData>(structuredClone(SAMPLE_XXX));
const xxxKey = ref(0);  // 强制重挂载
const toggleVisible = ref(true);  // toggle 响应式

const actions = computed<ShDemoAction[]>(() => XXX_ACTIONS.map((a) => ({ ...a })));
const secondaryActions = computed<ShDemoAction[]>(() =>
    XXX_SECONDARY.map((a) =>
        a.key === "toggle<X>" ? { ...a, active: toggleVisible.value } : { ...a },
    ),
);

const createEmpty = (): XxxData => ({ ...structuredClone(SAMPLE_XXX), /* 清空业务字段 */ });
const downloadJson = (d: unknown, filename: string): void => {
    const blob = new Blob([JSON.stringify(d, null, 2)], { type: "application/json" });
    const url = URL.createObjectURL(blob);
    const a = document.createElement("a");
    a.href = url; a.download = filename;
    document.body.appendChild(a); a.click(); document.body.removeChild(a);
    URL.revokeObjectURL(url);
};

const onAction = (key: string): void => {
    switch (key) {
        case "loadSample": data.value = structuredClone(SAMPLE_XXX); xxxKey.value++; ElMessage.success(i18n("advanced.xxx.message.loaded" as any)); break;
        case "clear": data.value = createEmpty(); xxxKey.value++; ElMessage.success(i18n("advanced.xxx.message.cleared" as any)); break;
        case "exportJson": downloadJson(data.value, "xxx.json"); ElMessage.success(i18n("advanced.xxx.message.exported" as any)); break;
        case "save": ElMessage.success(i18n("advanced.xxx.message.saved" as any)); break;
        case "toggle<X>": toggleVisible.value = !toggleVisible.value; ElMessage.info(toggleVisible.value ? i18n("advanced.xxx.message.xOn" as any) : i18n("advanced.xxx.message.xOff" as any)); break;
        case "help": ElMessage.info(i18n("advanced.xxx.message.helpHint" as any)); break;
    }
};

defineExpose({ loadData: (d?: XxxData) => { data.value = structuredClone(d ?? SAMPLE_XXX); xxxKey.value++; } });
</script>

<template>
```

## 假设与决策

### 假设

1. 底层组件的 Props/Events 已通过 Read 源码确认（见上表）
2. GraphViewer/GraphQueryBuilder 的根样式支持 height:100%（实施时若发现不支持，用 `:deep()` 覆盖）
3. AiCopilot 根样式支持 height:100%（实施时若发现不支持，用 `:deep()` 覆盖）

### 决策

1. **统一 `:key` 重挂载模式**：即使底层组件监听 props（如 DigitalTwinDesigner 监听 scene），仍用 `:key` 保证 clear/loadSample 行为一致且可预测
2. **OfficeEditor 修改 1 行**：将 `props.height ?? 600` 改为 `props.height != null ? props.height : '100%'`，向后兼容
3. **Map/Iot 用 ResizeObserver**：创建 `useElementHeight` 共享 composable，动态计算子组件高度
4. **KnowledgeGraphDemo 改左右分栏**：更适合企业级图查询场景
5. **toggle 类按钮无法控制底层时弹 ElMessage 提示**：如 PivotTable 的 toggleChart/toggleTotal，demo 工具栏按钮点击后提示"请在底层工具栏操作"
6. **RichText 三模式按钮互斥 active**：用三个 iconOnly 按钮（modeSimple/modeDefault/modeFull），computed 标记当前模式 active
7. **DigitalTwin toggleAutoSim 图标动态切换**：active 时 VideoPause，非 active 时 VideoPlay
8. **i18n key 扁平结构**：`advanced.<module>.toolbar.<action>` / `advanced.<module>.message.<field>`

## 风险与应对

| 风险 | 应对 |
| --- | --- |
| GraphViewer/GraphQueryBuilder 不支持 height:100% | 用 `:deep()` 覆盖根样式 |
| AiCopilot 不支持 height:100% | 用 `:deep()` 覆盖根样式 |
| Map/Iot ResizeObserver 在 el-tabs 切换时高度不准 | `useElementHeight` 监听 `.demo-stage`（稳定容器），offset 扣除 tab header |
| OfficeEditor 修改影响其他调用方 | 向后兼容：传 :height 时行为不变，不传时 100% |
| i18n key 与批次 2 冲突 | 9 个模块 key 前缀不同，无冲突 |
| browser_use agent 切 tab 失败 | 验证脚本明确指示先点"高级组件库" tab |

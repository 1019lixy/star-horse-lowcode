# 数字孪生与透视分析企业级整改 — 最终实施计划

> 创建日期：2026-07-20
> 上下文：用户对两个模块提出强烈不满，要求"大厂级"实用性，并行整改
> 用户原话核心诉求：
> - 数字孪生：组件添加后无法调整层级/位置/大小/框选；舞台太小；缺右键菜单（新建/前进/后退/预览/导入/导出/自定义组件/保存）
> - 透视分析：左侧字段操作图标不显示；数据管理不完善（数据源、字段编排）；"数字格式"挤成一列
> - 澄清答案：自定义组件=两者都要；数据源=JSON 粘贴 + API URL 拉取；整改顺序=两个并行；画布太小=侧栏过宽+底部图例占位

            method: apiMethod.value,

    } catch (e: any) {
        ElMessage.error(i18n("pivot.message.apiFetchFailed") + ": " + e.message);
    } finally { loading.value = false; }
};

const handleFieldUpdate = (field: "name" | "color", value: string): void => {
    if (!entity.value) return;
    designer.updateEntity(entity.value.id, { [field]: value } as any);

const handlePositionUpdate = (axis: "x" | "y" | "z", value: number): void => {

### B6. useDigitalTwinDesigner.ts — undo/redo + save/import/export

**文件**：`src/components/digitaltwin/composables/useDigitalTwinDesigner.ts`

**改动 1 - 增加 history 栈**：
```ts
import { computed, reactive, ref } from "vue";

const HISTORY_LIMIT = 50;
const historyStack = ref<string[]>([]);  // JSON 快照
const historyIndex = ref(-1);

const canUndo = computed(() => historyIndex.value > 0);
const canRedo = computed(() => historyIndex.value < historyStack.value.length - 1);

const pushHistory = (): void => {
    const snapshot = JSON.stringify(state.scene);
    // 截断 redo 部分
    historyStack.value = historyStack.value.slice(0, historyIndex.value + 1);
    historyStack.value.push(snapshot);
    if (historyStack.value.length > HISTORY_LIMIT) {
        historyStack.value.shift();
    } else {
        historyIndex.value++;
    }
};

const undo = (): void => {
    if (!canUndo.value) return;
    historyIndex.value--;
    state.scene = JSON.parse(historyStack.value[historyIndex.value]);
    state.selectedEntityId = null;
};

const redo = (): void => {
    if (!canRedo.value) return;
    historyIndex.value++;
    state.scene = JSON.parse(historyStack.value[historyIndex.value]);
    state.selectedEntityId = null;
};

const clearHistory = (): void => {
    historyStack.value = [];
    historyIndex.value = -1;
    pushHistory();  // 初始快照
};
```

## 五、假设与决策

### 假设
1. 用户接受的"自定义组件"= 选中场景中已有实体保存为复合模型 + 库管理（搜索/分类/收藏/导入导出），存储于 localStorage
2. 数据源=JSON 粘贴 + API URL 拉取（不含 CSV 上传、不含手动表格录入）
3. 撤销/重做使用 JSON 快照栈（max 50），实时拖拽不每帧推栈，仅在拖拽结束 commit
4. TransformControls 默认 translate 模式，工具栏后续可切换 rotate/scale（本批次提供按钮但不强制实现完整 scale 逻辑）
5. 框选用 Shift+拖拽触发，避免与单击选中冲突
6. 右键菜单通过 viewport 派发，主壳统一处理 action，避免子组件耦合业务逻辑

### 决策
1. **不引入新依赖**：所有 Three.js addons 已内置（node_modules/three/examples/jsm/*）
2. **保留旧 Canvas 2D 相机系统兼容**：DtToolbar 仍接受 camera prop，不影响 3D 视口
3. **历史栈放 composable 不放组件**：保证状态一致性，跨组件调用 undo/redo
4. **localStorage 而非 IndexedDB**：自定义组件数量预期 <100，localStorage 5MB 足够
5. **预览模式独立路由**：通过 previewMode ref 控制，不修改 URL
6. **PivotTable 通过 defineExpose 暴露 openDataManager**：保持封装，PivotDemo 通过 ref 调用

## 六、验证步骤

### 数字孪生模块验证
1. **舞台尺寸**：打开 DigitalTwinDemo，画布应占据屏幕主要区域，左右面板可拖拽缩放，可一键折叠；图例浮动在右上角可折叠
2. **属性编辑**：选中实体 → 修改位置 X → 3D 视口中实体应实时移动；修改颜色 → 实体颜色变化；修改尺寸 → 包围盒变化
3. **层级管理**：实体列表中点上移/下移 → entities 数组顺序变化（影响 z-index 渲染）；点显示/隐藏 → 实体在视口中消失/出现；点锁定 → TransformControls 不可 attach
4. **拖拽移动**：切到 edit 模式 → 选中实体 → 出现 TransformControls 红绿蓝箭头 → 拖拽箭头实体跟随移动 → 松手后 entity.position 更新且 history 推栈
5. **框选**：edit 模式 + Shift + 拖拽 → 出现蓝色选择框 → 松开后框内实体全部选中并高亮
6. **右键菜单**：在视口空白处右键 → 弹出菜单（新建/撤销/重做/预览/导入/导出/自定义组件/保存）；在实体上右键 → 菜单额外显示复制/删除
7. **撤销/重做**：移动实体后点撤销 → 实体回到原位；点重做 → 再次移动
8. **保存/导入/导出**：导出场景 → 下载 JSON；清空场景 → 导入刚才的 JSON → 场景恢复
9. **自定义组件**：选中多个实体 → 自定义组件弹窗 → 保存 → 在库管理 Tab 看到新组件 → 点击"添加到场景" → 实体被添加
10. **预览模式**：点预览 → 隐藏所有面板仅显示 3D 视口全屏 → 点退出或 ESC 恢复

## 一、摘要

用户要求把数字孪生模块做成企业级、可落地的设计器。当前已完成的批次（B3 属性面板 / B4 实体列表 / B9 图标 / B11 类型 / B12 部分 i18n）解决了"看得见"的问题，但用户核心痛点——**"组件添加到了舞台，我就没法调整，层级，位置，大小，框选...鼠标右键，新建，前进，后退，预览，导入，导出，自定义组件，保存等"**——仍未解决。

本计划完成剩余 5 个任务（B5 / B7 / B8 / B2 / B10）+ 收尾（补全缺失 i18n、移除 `as any`、HMR 验证），让数字孪生设计器具备：
- 3D 视口内拖拽移动 / 旋转 / 缩放实体（TransformControls Gizmo）
- Shift+ 拖拽框选多个实体
- 右键上下文菜单（新建/撤销/重做/预览/导入/导出/自定义组件/保存 + 实体级：复制/删除/置顶/置底/锁定/重命名）
- 顶部工具栏 8 个按钮组（场景/历史/视角/变换模式/模拟/添加/面板/预览），全部 ShSvgIcon

### 5.4 TransformControls 实现

```ts
let transformControls: TransformControls | null = null;

const setupTransformControls = (): void => {
    const inst = engine.value;
    if (!inst || transformControls) return;
    transformControls = new TransformControls(inst.cameraRig.camera, inst.renderer.domElement);
    // 拖拽时禁用相机轨道（相机轨道由 DtCameraRig 内部 OrbitControls 提供，通过 dragging-changed 事件暂停）
    transformControls.addEventListener("dragging-changed", (event: any) => {
        if (inst.cameraRig.orbitControls) {
            inst.cameraRig.orbitControls.enabled = !event.value;
        }
    });
    // 拖拽中实时派发位置/尺寸变化
    transformControls.addEventListener("objectChange", () => {
        const obj = transformControls?.object;
        if (!obj) return;
        const entityId = obj.userData?.entityId as string | undefined;
        if (!entityId) return;
        const position = { x: obj.position.x, y: obj.position.y, z: obj.position.z };
        const size = extractSizeFromObject(obj);
        emit("entity-transform", entityId, position, size);
    });
    // 拖拽结束（mouseUp）派发 entity-transform-end 以触发 pushHistory
    transformControls.addEventListener("mouseUp", () => {
        const obj = transformControls?.object;
        const entityId = obj?.userData?.entityId as string | undefined;
        if (entityId) emit("entity-transform-end", entityId);
    });
    inst.scene.add(transformControls);  // 注意：加到 scene 而非 currentRoot，避免被 syncEntitiesToScene 清空
};

/** 从 Object3D 提取 size（根据 geometry 类型回填 DtSize3D） */
const extractSizeFromObject = (obj: Object3D): DtSize3D => {
    const mesh = obj as Mesh;
    const geo = mesh.geometry;
    if (geo instanceof BoxGeometry) {
        return { width: geo.parameters.width, height: geo.parameters.height, depth: geo.parameters.depth, radius: 0 };
    }
    if (geo instanceof CylinderGeometry) {
        return { width: 0, height: geo.parameters.height, depth: 0, radius: geo.parameters.radius };
    }
    if (geo instanceof PlaneGeometry) {
        return { width: geo.parameters.width, height: 0, depth: geo.parameters.height, radius: 0 };
    }
    if (geo instanceof SphereGeometry) {
        return { width: 0, height: 0, depth: 0, radius: geo.parameters.radius };
    }
    return { width: 0, height: 0, depth: 0, radius: 0 };
};

/** 附加 Gizmo 到指定实体 */
const attachTransformToSelected = (entityId: string | null): void => {
    if (!transformControls || !engine.value) return;
    if (!entityId || !props.editMode) {
        transformControls.detach();
        return;
    }
    // 锁定实体不附加
    if (props.lockedIds.includes(entityId)) {
        transformControls.detach();
        return;
    }
    const root = engine.value.sceneManager.currentRoot;
    let target: Object3D | null = null;
    root.traverse((obj) => {
        if (obj.userData?.entityId === entityId) target = obj;
    });
    if (target) {
        transformControls.attach(target);
        transformControls.setMode(props.transformMode);
    } else {
        transformControls.detach();
    }
};

/** 设置变换模式 */
const setTransformMode = (mode: "translate" | "rotate" | "scale"): void => {
    if (transformControls) transformControls.setMode(mode);
};

/** 分离 Gizmo */
const detachTransform = (): void => {
    transformControls?.detach();
};
```

**生命周期集成**：
- `onMounted` 在 `init()` 成功后调用 `setupTransformControls()`
- `onBeforeUnmount` 调用 `transformControls?.dispose(); transformControls = null`

**watch 集成**：
- `watch(() => props.editMode, (m) => { if (!m) detachTransform(); })`
- `watch(() => props.transformMode, (m) => setTransformMode(m))`
- `watch(() => props.lockedIds, () => attachTransformToSelected(currentSelectedEntityId))` —— 锁定变化时重新评估

### 5.5 Shift+ 拖拽框选实现

```ts
let selectionBox: SelectionBox | null = null;
let selectionHelper: SelectionHelper | null = null;

const handleCanvasMouseDown = (e: MouseEvent): void => {
    if (!props.editMode) return;
    // 仅 Shift+左键触发框选
    if (e.button !== 0 || !e.shiftKey) return;
    const inst = engine.value;
    if (!inst) return;
    // 已有 Gizmo 拖拽中则不触发
    if (transformControls?.dragging) return;

    selectionBox = new SelectionBox(inst.cameraRig.camera, inst.scene);
    selectionHelper = new SelectionHelper(selectionBox, inst.renderer, "dt-box-select-helper");
    const rect = inst.renderer.domElement.getBoundingClientRect();
    selectionBox.startPoint.set(
        ((e.clientX - rect.left) / rect.width) * 2 - 1,
        -((e.clientY - rect.top) / rect.height) * 2 + 1,
        0.5,
    );
    selectionBox.endPoint.copy(selectionBox.startPoint);
    selectionBox.select();
};

const handleCanvasMouseMove = (e: MouseEvent): void => {
    if (!selectionBox || !selectionHelper) return;
    const inst = engine.value;
    if (!inst) return;
    const rect = inst.renderer.domElement.getBoundingClientRect();
    selectionBox.endPoint.set(
        ((e.clientX - rect.left) / rect.width) * 2 - 1,
        -((e.clientY - rect.top) / rect.height) * 2 + 1,
        0.5,
    );
    // 重新计算选中集
    selectionBox.startPoint.copy(selectionBox.selectionStart);
    const prevSelected = selectionBox.collection.slice();
    selectionBox.select();
    // 仅保留有 userData.entityId 的对象
    const entityIds = selectionBox.collection
        .filter((obj) => obj.userData?.entityId && !props.lockedIds.includes(obj.userData.entityId))
        .map((obj) => obj.userData.entityId as string);
    // 去重
    emit("box-select", [...new Set(entityIds)]);
};

const handleCanvasMouseUp = (e: MouseEvent): void => {
    if (selectionHelper) {
        selectionHelper.dispose();
        selectionHelper = null;
    }
    selectionBox = null;
};
```

**模板**：在 `<canvas>` 上追加 `@mousedown="handleCanvasMouseDown"` `@mousemove="handleCanvasMouseMove"` `@mouseup="handleCanvasMouseUp"`（保留原有 `@click` 和 `@mousemove="scheduleMouseEvent"`，新增的 mousedown/mousemove/mouseup 与原 hover 节流不冲突，因为框选仅在 editMode + Shift 时触发）。

> 注意：原 `scheduleMouseEvent` 用于 hover 高亮，与框选的 mousemove 共存——框选 mousemove 在 `selectionBox` 存在时才工作，否则直接 return，不影响 hover。

```ts
const handleKeyDown = (e: KeyboardEvent): void => {
    // 预览模式禁用所有编辑快捷键
    if (previewMode.value) {
        if (e.key === "Escape") handleTogglePreview();
        return;
    }
    const ctrl = e.ctrlKey || e.metaKey;
    const target = e.target as HTMLElement;
    // 输入框内不触发（除 Ctrl+S）
    const isInput = target.tagName === "INPUT" || target.tagName === "TEXTAREA" || target.isContentEditable;

    if (ctrl && e.key === "z" && !e.shiftKey) {
        e.preventDefault();
        designer.undo();
    } else if ((ctrl && e.key === "y") || (ctrl && e.shiftKey && e.key === "Z")) {
        e.preventDefault();
        designer.redo();
    } else if (ctrl && e.key === "s") {
        e.preventDefault();
        handleSaveScene();
    } else if (ctrl && e.key === "d" && !isInput) {
        e.preventDefault();
        if (designer.state.selectedEntityId) designer.duplicateEntity(designer.state.selectedEntityId);
    } else if (e.key === "Delete" && !isInput) {
        if (designer.state.selectedEntityId) designer.removeEntity(designer.state.selectedEntityId);
    } else if (e.key === "Escape" && !isInput) {
        if (contextMenu.visible) contextMenu.visible = false;
        else designer.selectEntity(null);
    }
};

onMounted(() => {
    document.addEventListener("keydown", handleKeyDown);
});

onBeforeUnmount(() => {
    document.removeEventListener("keydown", handleKeyDown);
});
```

## 十三、假设与决策

1. **框选多选 vs 单选**：当前 `useDigitalTwinDesigner.state.selectedEntityId` 为单值，框选返回多 ID 时仅取第一个 + ElMessage 提示数量。多选支持需重构 designer 状态机，超出本计划范围。
2. **自定义组件 MVP 仅支持单实体转组件**：将选中实体转为 1 部件的 DtModelPreset。多实体组合需额外实现"组合选择"概念，留待后续。
3. **TransformControls 附加到 scene 而非 currentRoot**：避免 `syncEntitiesToScene` 清空 currentRoot 时 Gizmo 被移除。
4. **预览模式复用同一 DtSceneViewport 实例**：通过 v-if 切换会导致 engine 重新初始化，故使用两个 viewport 实例（编辑态 + 预览态），共享 designer.state.scene。
5. **import/export/save 图标**：从原 DtToolbar 内联 SVG 迁移到 registry，保持视觉一致。
6. **`i18n(preset.labelKey as any)` 保留**：动态变量 key 无法静态校验，保留 `as any` 是合理的 TypeScript 妥协。
7. **Ctrl+S 全局拦截**：`e.preventDefault()` 阻止浏览器默认保存页面行为。
8. **文件 IO 不使用 Blob/Base64 大文件方案**：导入用 FileReader.readAsText（小 JSON），导出用 Blob + URL.createObjectURL + a.download（项目约定允许，仅禁止大文件用 Blob/Base64 下载）。

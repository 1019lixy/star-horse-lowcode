### 任务 1：创建 `panels/DtPerformanceHud.vue`（🔴 紧急）

**路径**：`e:\lixycode\shplugin\src\components\digitaltwin\panels\DtPerformanceHud.vue`

**职责**：浮层显示引擎性能指标，订阅 `engine.performance.onStats` 实时更新。

**Props**（必须与 DtSceneViewport.vue 第 482 行调用一致）：
```typescript
defineProps<{
    engine: ShallowRef<DtEngine | null>;
    fps: number;  // DtSceneViewport 已通过 onStats 同步到自己的 fps ref，可作为兜底
}>();
```

**实现要点**：
- `import type { DtEngine, DtPerformanceStats } from "../core/DtEngine"`（DtEngine 已导出，DtPerformanceStats 从 `../types` 导入）
- 本地 ref `stats: Ref<DtPerformanceStats | null>`，`onMounted` 调用 `props.engine.value?.performance.onStats(s => stats.value = s)`，保存返回的 unsubscribe 函数
- `onBeforeUnmount` 调用 unsubscribe
- `watch(() => props.engine.value, (e, oldE, onCleanup) => {...})` 处理引擎实例变化（虽然 DtSceneViewport 内引擎 init 后基本不变，但稳健起见保留）
- **显示字段**：FPS（绿/黄/红三色：<30 红、<55 黄、≥55 绿）、Frame Time (ms)、Draw Calls、Triangles（缩写为 K/M）、Geometries、Textures、Programs、Instanced Meshes、JS Heap（仅 Chromium，`stats.jsHeapSize` 存在时显示 MB）
- **视觉**：右上角浮层，半透明深色背景（`rgba(30,30,30,0.7)` + `backdrop-filter: blur(8px)`），monospace 字体，符合 VS Code 暗色主题
- **折叠**：提供 `el-icon` 折叠/展开按钮，折叠时仅显示 FPS 一行（节省屏幕空间）
- **不使用 jQuery**：纯原生 + Vue 模板
- **rAF 节流**：onStats 回调本身已是 1 秒一次（DtPerformanceMonitor 内部节流），无需额外 rAF

**模板骨架**：
```vue
<template>
    <div class="dt-perf-hud" :class="{ collapsed: !expanded }">
        <div class="dt-perf-header">
            <span class="dt-perf-title">{{ i18n("digitaltwin.performance.title") }}</span>
            <el-icon class="dt-perf-toggle" @click="expanded = !expanded">
                <ArrowDown v-if="expanded" /><ArrowUp v-else />
            </el-icon>
        </div>
        <div v-show="expanded" class="dt-perf-body">
            <div class="dt-perf-row">
                <span class="dt-perf-label">FPS</span>
                <span class="dt-perf-value" :class="fpsClass">{{ stats?.fps ?? fps }}</span>
            </div>
            <!-- frameTime / drawCalls / triangles / geometries / textures / programs / instancedMeshes / jsHeapSize -->
        </div>
    </div>
</template>
```

**样式要点**：
- `position: absolute; top: 12px; right: 12px; z-index: 10;`

**注意**：DtToolbar 的视角切换仍调用旧 `useDigitalTwinCamera`（Canvas 2D 投影相机），与 DtSceneViewport 内的 Three.js 相机是**两套独立系统**。批次 1 内允许这种"工具栏视角按钮先 no-op + DtSceneViewport 自带视角预设按钮真正生效"的过渡状态。`handleViewChange` 内仍可调用 `camera.applyViewPreset(preset)`（保持兼容，不影响 3D 视口），同时通过 ref 调用 `viewportRef.value?.applyPreset(preset)` 同步 3D 视口（在 DtSceneViewport.vue `defineExpose` 中已暴露 `sceneApi`，可补加 `applyPreset` 暴露）。

为简化批次 1：DtToolbar 的视角按钮**保留触发旧 camera.applyViewPreset**（不影响 3D），用户主要用 DtSceneViewport 自带的视角预设按钮操作 3D 视口。批次 2 再统一相机系统。

## 假设与决策（Assumptions & Decisions）

### 已确定的实施决策（不再询问用户）

1. **不删除 DigitalTwinViewer.vue**：保留作为 @deprecated 兜底，新增 DigitalTwinDesigner.vue 作为企业级主壳。这样既符合蓝图"改名"精神，又不破坏外部 import 路径。
2. **i18n 仅补 2 语言**：项目 langList 仅 zh_CN + en_US，5 语言为批次 6 范围。
3. **DtToolbar 视角按钮与 3D 视口相机解耦**：批次 1 内 DtToolbar 仍调用旧 `useDigitalTwinCamera`（Canvas 2D 投影），不影响 3D 视口；用户用 DtSceneViewport 自带的视角预设按钮操作 3D。批次 2 统一相机系统。这是过渡状态，符合"批次 1 仅做引擎骨架 + 视口替换"的边界。
4. **DtSceneViewport 已暴露 `sceneApi`/`engine`/`ready`/`syncEntitiesToScene`**：DigitalTwinDesigner 如需调用 3D 视口方法（如 applyPreset 同步），通过 ref 访问。批次 1 不强制同步两套相机，仅在用户点击 DtSceneViewport 内置按钮时操作 3D。
5. **不引入新依赖**：批次 1 仅用 three（已安装），不引入 postprocessing/meshoptimizer 等（批次 2+ 范围）。
6. **不修改 core/*.ts 既有实现**：5 个核心类已通过自洽设计与类型检查，本批次仅在 panels/composables/顶层壳层面集成。若验证阶段发现 core 有 bug，最小化补丁修复，不重构。
7. **DtPerformanceHud 不做历史曲线图**：批次 1 仅显示当前数值（FPS/DrawCall/...），历史曲线在批次 6 性能优化时补。
8. **`@deprecated` 标记仅注释不改逻辑**：保证向后兼容，外部消费者不破坏。

### 风险与应对

| 风险 | 应对 |
|---|---|
| DtSceneViewport.vue 中 `engine.performance.onStats` 回调签名与 DtPerformanceHud 期望不一致 | 实施前先 Read `core/DtPerformanceMonitor.ts` 确认 onStats 签名与 DtPerformanceStats 字段 |
| 旧 DtEntity 的 `position.y` 是底面，DtSceneViewport 已处理（cube 加 height/2），但 sphere/cylinder 未处理可能导致下沉 | 验证阶段观察视觉，若有下沉，在 DtSceneViewport.vue `entityToObject3D` 内补 cylinder/sphere 的 y 偏移（最小补丁）|
| Three.js external 在 dev 模式下未预构建导致启动慢 | vite.config.ts 已 `optimizeDepsList.push("three")`，dev 模式会预构建，无问题 |
| WebGL2 在某些环境不可用 | DtSceneViewport 已有 `checkWebGL()` 降级提示；验证阶段如本机无 WebGL，记录为环境问题不影响交付 |
| ResizeObserver 在容器初始尺寸为 0 时不触发 | DtSceneViewport `onMounted` 已直接调用 `applyPreset`，且 ResizeObserver 会捕获后续尺寸变化；如初始空白，验证阶段补 `nextTick` 后再次 resize |
